# Визуальные источники CP-2.1

## Концепции

- **A — A-Design-final / «Завод-Гарант»**: [Figma, node 777:4346](https://www.figma.com/design/lhApyFagVFlyMKmZPkSXzH/Cascade-Branding-Site?node-id=777-4346). Шрифтовая пара: Bebas Neue + Golos Text.
- **B — B-Design-final / «Инженерная система»**: [Figma, node 777:5058](https://www.figma.com/design/lhApyFagVFlyMKmZPkSXzH/Cascade-Branding-Site?node-id=777-5058). Шрифтовая пара: IBM Plex Sans + IBM Plex Mono.

Оба desktop-фрейма имеют ширину 1790 px. Основной контентный контейнер — 1368 px.

## Зафиксированные основы

Утверждённые фирменные цвета: `#EE322D`, `#131718`, `#fff`. Дополнительные нейтральные цвета: поверхность `#F3F4F4`, усиленная поверхность `#E5E7E7`, граница `#D8DCDC`, вторичный текст `#5F6768`.

До этапа финальной визуальной полировки тексты текущего HTML-прототипа и перенесённых partial-компонентов имеют приоритет над расхождениями с Figma. Figma задаёт композицию и визуальную систему, но не заменяет контент.

Финальные изображения продукции, Hero, завода и объектов ещё не выбраны и в CP-2.1A не добавляются. В Figma также не отрисованы полный футер, часть секций и Каталог. В следующих визуальных подэтапах утверждённые системы A и B следует экстраполировать на эти компоненты без создания третьей концепции.

Мобильный header в CP-2.1B должен включать логотип, кнопку звонка с иконкой, кнопку почты с иконкой и кнопку меню. В CP-2.1A эти элементы не добавляются.
