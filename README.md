# Интерактивный прототип сайта «Каскад»

Статический многостраничный прототип на Vite, обычном HTML, CSS и vanilla JavaScript. Сквозные HTML-компоненты подключаются из `src/partials` во время сборки с помощью Handlebars; браузер получает готовые статические страницы без `fetch()`.

## Требования

- Node.js 20.19+ или 22.12+;
- npm 10+.

## Установка

```sh
npm install
```

## Локальная разработка

```sh
npm run dev
```

Vite выведет адрес локального сервера. Исходные страницы находятся в `src/pages`.

## Сборка

```sh
npm run build
```

Результат записывается в `dist`: `index.html`, `catalog.html` и общие ресурсы в `dist/assets`.

## Предпросмотр сборки

```sh
npm run preview
```

## Структура

- `src/pages` — входные HTML-страницы;
- `src/partials` — подключаемые на этапе сборки сквозные компоненты;
- `src/styles` — общие стили и будущие темы;
- `src/scripts` — vanilla JavaScript;
- `src/assets` — шрифты, иконки и изображения;
- `reference/prototype-original` — неизменённые файлы исходного HTML-прототипа;
- `docs` — проектная документация;
- `dist` — результат сборки (не хранится в Git).

Текущий подэтап CP-1.1A создаёт только технический каркас. Визуальная система, адаптив, интерактивные меню, формы, модальное окно и темы намеренно не реализованы.
